# splunk/attack_data (Apache-2.0).

# The samples are not copied into this repository. They are also not cloned:
# that repository keeps its logs in Git LFS, so a plain clone brings down
# pointer files instead of data, and a `git lfs pull` needs the client and
# counts against the upstream project's bandwidth. Each file is fetched on its
# own over plain HTTPS from the media endpoint, at the commit below, which
# needs nothing but curl and cannot drift.
#
# The files land flat in datasets-linux/ under their own names. Zircolite
# reports a match by file name rather than by path, so the names have to stay
# unique — add a sample whose name collides with one already here and the
# manifests become ambiguous.
#
# Format: one repository path per line. Blank lines and # are ignored.
